# SHEEP GEM v2 独立评分组件

这个 TypeScript 组件从调用方传入的观测和检查结果计算 SHEEP 五维分数及周趋势。运行时零第三方依赖，不连接网络、数据库或模型服务。

## 本地运行

Node.js 20 及以上；交付包附有编译后的 JavaScript 和类型声明：

```sh
node examples/synthetic.mjs
node --test test/*.test.mjs
```

从 TypeScript 重新构建：

```sh
npm ci
npm test
```

安装开发依赖需要访问包源；评分和测试本身离线运行。该组件尚未发布至 npm。

## 数据边界

- 示例与测试全部人工构造，不是生产数据抽样或脱敏副本。
- 评分输入仅需日期、匿名模型标识、排名、监测标记，以及网站检查状态。
- 不要求品牌名、域名、问题文本、回答正文、客户标识或生产记录 ID。
- 引用判断由调用方转换成布尔值后传入，不传送引用原文。
- 不包含服务地址、服务器连接、数据库备份、账户、密钥或环境文件。

## 评分约定

GEM = S×25% + H×25% + E1×20% + E2×15% + P×15%。S 与 E2 至少需要 20 次观测，任何一维缺少分数时不生成总分。20 次只是实现门槛，不代表统计置信度。分数是启发式指标，不代表客观权威认证、AI 推荐概率或商业效果保证。

调用方须先验证输入、去重、统一采样方式和时区。`own=-1` 表示未提及、`0` 表示提及但没有排名、正整数表示排名。日期使用同一时区下的有效 `YYYY-MM-DD`；模型标识使用 `model-a` 等匿名值即可。

新版独立组件保留原有公式与主要行为，但增加周趋势的截至日期限制：不会引用 `today` 之后的观测或站点快照。它与旧版单次官网分析评分不可直接比较。

特别注意继承行为：未检测爬虫访问时该项默认可访问；旧抓取没有 HTTPS 项时会重新分配其他权重；未提供证据检查时对应部分为零。接入时应传入完整检查结果，不能把缺失检查解释为已核验通过。
