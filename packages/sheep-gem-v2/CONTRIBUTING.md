# Contributing

Use Node.js 20+, run `npm ci` and `npm test`, and explain any formula or data-contract changes. Update the algorithm version and methodology whenever scoring behavior changes.

Include a small fully artificial reproduction and expected result. Do not submit real brands, customer conversations, source documents, screenshots of production systems, credentials, server addresses, environment files or database exports.

Useful contributions include independent validation studies with permissioned data and aggregate findings, input validation, checks for uncertainty and sampling bias, alternative explicit scoring policies, and additional offline examples.
